# Release 2.0.4

## Participants

Andrei Makarov (@amkisko)

## Decisions

Cut 2.0.4 as a patch. Ship experimental `StyleCapsule.isolation_level = :fiber` (default stays `:thread`) and keep the CSS / stylesheet-registry / instrumentation hot-path optimizations as the only behavior. Do not flip Rails `ActiveSupport::IsolatedExecutionState.isolation_level` from this API. Keep the experimental label until a production Fiber server validates the API. No custom C extension.
